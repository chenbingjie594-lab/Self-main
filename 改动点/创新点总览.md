# 两个创新点总览

> 当前状态：创新点一 RDA 已完成并确定 v4 为主线；创新点二 RAPS 尚未实现。  
> 总体原则：优先提高生成质量和下游价值，baseline 独立保留，所有方法采用公平训练与评测设置。

## 1. 创新点一：RDA

RDA（Reference-Decoupled Anomaly Adapter，参考驱动的解耦缺陷适配器）解决 baseline 缺陷偏弱、形态退化以及粗 mask 缺少真实纹理和边缘信息的问题。

其核心不是调节推理强度，而是从真实缺陷参考中学习局部形态：

- 冻结 VAE 提取参考缺陷 latent；
- 在粗参考区域内编码局部信息，压缩成 reference tokens；
- reference tokens 只加入条件分支，保持 CFG 对称性；
- 自适应门控限制逐样本 token 强度，避免亮度、颜色和面积失控；
- 从原始 SD2 权重重新训练 U-Net 与 RDA，监督目标是真实缺陷和真实粗标注。

在 held-out 30% 真实数据上的宏平均结果为：baseline KID×1000 为 51.1，RDA v4 为 44.0，降低 13.8%；IC-LPIPS×100 分别为 26.4 和 26.2，多样性基本保持。因此最终采用 v4，v5–v8 只保留为未超过主线的探索性消融。

详细设计、损失和实验结果见 [模块1-RDA.md](./模块1-RDA.md)。

## 2. 创新点二：RAPS

RAPS（Reference-Aware Progressive Selection，参考感知的渐进式候选筛选）面向扩散采样的偶发失败。它对同一 normal、粗空间先验和类别生成多个候选，再综合评价：

- 与真实参考缺陷的特征相似度；
- 相对 normal 的有效异常差异；
- mask 外背景一致性；
- 缺陷面积与空间合理性；
- 过曝、过暗、全黑和颜色偏移；
- 批次内多样性。

RAPS 不以“与 normal 差异越大越好”为准则，避免选中强光斑、巨大色块或背景损坏样本。它是推理阶段的质量控制，不代替 RDA 的训练能力。

详细方案见 [模块2-RAPS.md](./模块2-RAPS.md)。

## 3. 公平消融

```text
E0：冻结的原始 Baseline
E1：从相同 SD2 权重训练相同步数的 Baseline
E2：完整 RDA v4
E3：RDA v4 + RAPS
```

所有实验固定数据划分、训练步数、prompt、normal 输入、粗空间先验、seed、scheduler、CFG 和采样步数。核心指标为 KID、IC-LPIPS、mask 外背景保持、失败率以及下游检测/分割增益。

运行和版本管理见 [RDA-RAPS实施路线.md](./RDA-RAPS实施路线.md)。
